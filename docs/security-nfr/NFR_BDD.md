# NFR_BDD.md — Приёмка в формате Gherkin

Feature: Защита от перебора паролей
  Scenario: Блокировка при слишком частых попытках входа
    Given пользователь с IP 192.168.1.100
    When он отправляет 6 запросов на /login за 60 секунд
    Then 6-й запрос должен вернуть статус 429 Too Many Requests

Feature: Безопасность токенов
  Scenario: Access token истекает через 15 минут
    Given выданный access token
    When прошло 16 минут
    Then запрос с этим token должен вернуть 401 Unauthorized

Feature: Производительность
  Scenario: Сервис выдерживает нагрузку
    Given сервис на тестовом окружении
    When запускается тест с 50 запросов в секунду на /login
    Then p95 времени ответа должен быть ≤ 300 ms

Feature: Устойчивость к сбоям
  Scenario: Сервис не падает при высокой нагрузке
    Given сервис аутентификации
    When подается 200 запросов в секунду (в 4 раза выше нормы)
    Then сервис не должен возвращать 500 ошибки
    And должен восстановиться после снижения нагрузки
